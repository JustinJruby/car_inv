# Data Model: Car Inventory

Entities come from the spec's Key Entities section. Field names are Rails conventions; the table and column types are decisions recorded in `research.md`.

## User (staff)

Generated by `bin/rails generate authentication`.

| Field | Type | Rules |
|-------|------|-------|
| `email_address` | string | Required, unique, normalized to lowercase and stripped. Staff contact for the nightly report. |
| `password_digest` | string | From `has_secure_password`. Minimum length 12. |

Relationships: has many Sessions.

## Session (staff)

Generated by the authentication generator.

| Field | Type | Rules |
|-------|------|-------|
| `user_id` | reference | Required. |
| `ip_address` | string | Optional. Recorded for audit. |
| `user_agent` | string | Optional. |

## Dealership

| Field | Type | Rules |
|-------|------|-------|
| `name` | string | Required, unique. |

Relationships: has many Cars. Each car belongs to one dealership (spec assumption).

## Car

| Field | Type | Rules |
|-------|------|-------|
| `dealership_id` | reference | Required. |
| `make` | string | Required. |
| `model` | string | Required. |
| `year` | integer | Required. Between 1900 and next calendar year. |
| `vin` | string(17) | Required. Normalized to uppercase. Exactly 17 letters or digits. Unique among cars whose status is not sold (partial index). |
| `mileage` | integer | Required. Zero or greater. |
| `asking_price_cents` | integer | Required. Greater than zero. Stored in cents to avoid floating-point rounding. |
| `status` | integer enum | Required. `available` (0), `reserved` (1), `sold` (2). Default `available`. |
| `price_dropped_at` | datetime | Set to the current time when `asking_price_cents` decreases. Nil if no reduction. |
| `contact_name` | string | Optional. Private to staff (FR-020). |
| `contact_phone` | string | Optional. Private to staff (FR-020). |
| `contact_email` | string | Optional. Private to staff (FR-020). |
| `lock_version` | integer | Default 0. Optimistic locking (FR-021). |
| `created_at`, `updated_at` | datetime | `updated_at` drives the stale-listing report (FR-017). |

Attached and rich-text associations (not table columns):

- `photos`: Active Storage, many attachments. Accepts JPEG, PNG, and WebP.
- `description`: Action Text rich text.

Scopes:

- `available`: status is `available` only. Used for every customer view (FR-013).
- `stale`: `updated_at < 60.days.ago`.
- Filter scopes: `by_make`, `priced_between`, `year_between`, `with_feature`.

Validation rules from requirements:

- FR-003: Create, edit, and remove are allowed for staff only.
- FR-013: Customer searches exclude `reserved` and `sold`, using the `available` scope.
- VIN uniqueness uses a different rule from the `available` scope: unique among cars whose status is not `sold`. The two rules are named separately in the code.

## Feature

| Field | Type | Rules |
|-------|------|-------|
| `name` | string | Required, unique, normalized to lowercase and stripped (for example, "AWD", "leather seats"). |

Relationships: has many Cars through CarFeature.

## CarFeature (join)

| Field | Type | Rules |
|-------|------|-------|
| `car_id` | reference | Required. `touch: true`, so tag changes count as edits. |
| `feature_id` | reference | Required. |

Unique index on `(car_id, feature_id)`.

## Favorite (browser only, no table)

Stored in `localStorage` under one key:

```json
{
  "favorites": {
    "<car_id>": { "saved_at": "<ISO timestamp>", "last_seen_at": "<ISO timestamp>" }
  }
}
```

- A favorite refers to a car by ID. If the car is removed, the favorite shows it as unavailable (edge case).
- The badge shows when `price_dropped_at` (from the server) is later than `last_seen_at`.

## Share Link (no table)

- A signed token from `Car.generates_token_for :share, expires_in: 7.days`.
- Not stored. Expiry is part of the token.
- Maps to exactly one car.

## Price Drop Marker

Represented by `Car.price_dropped_at`. There is no separate table (see `research.md` #10).

## State transitions

| From | To | Trigger |
|------|-----|---------|
| available | reserved | Staff set status |
| reserved | available | Staff set status |
| available or reserved | sold | Staff set status. The car leaves the VIN uniqueness check and public search. |
| sold | available or reserved | Staff set status. Allowed, and the VIN is checked for uniqueness again. |
